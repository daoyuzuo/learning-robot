**Goal:** 作答后可请求 AI 讲评；有 rubric 的题型附带参考评分，记入 `llm_review` 证据，但不影响掌握度与复习。

**Architecture:** 在 `tutor/` 下新增 `review.py`（上下文/提示词/解析）、`review_store.py`（按 evidence 缓存）、`review_service.py`（编排）。参考评分作为新的 evidence kind 追加，现有 mastery/BKT/FSRS 只认已知 kind，因此天然隔离。Web 层负责追加证据并调用 `LearningService.record`。

**Tech Stack:** Python 3.10+、httpx、FastAPI、Jinja2、原生 JS、pytest。

**Spec:** [2026-10-25-p2.3-review-design.md](../specs/2026-10-25-p2.3-review-design.md)

## Global Constraints

- 代码标识符与注释用英文，面向用户的文案用中文。
- `llm_review` 不得进入 mastery / BKT / FSRS：不得修改 `mastery/rule.py` 的 `KIND_WEIGHTS`，不得让 `replay_bkt` 接受它。
- 讲评上下文包含正确答案与解析；追问上下文（`tutor/context.py`）必须继续排除答案。
- 测试不联网：客户端用 `httpx.MockTransport`，服务用假 `LlmClient`。
- 现有 266 个测试必须保持全绿。
- 缓存键是 `evidence_id`；`refresh=true` 才重新调用模型。
- `prompt_version` 固定为 `review/1`。

```python
    def list(
        self,
        lesson_id: str | None = None,
        concept_id: str | None = None,
        kind: str | None = None,
        limit: int = 100,
    ) -> list[EvidenceEvent]:
        sql = "SELECT * FROM evidence WHERE 1=1"
        params: list[Any] = []
        if lesson_id:
            sql += " AND lesson_id = ?"
            params.append(lesson_id)
        if concept_id:
            sql += " AND instr(concept_ids, ?) > 0"
            params.append(json.dumps(concept_id, ensure_ascii=False))
        if kind:
            sql += " AND kind = ?"
            params.append(kind)
        sql += " ORDER BY created_at DESC LIMIT ?"
        params.append(limit)
        with sqlite3.connect(self.path) as conn:
            conn.row_factory = sqlite3.Row
            rows = conn.execute(sql, params).fetchall()
        return [self._row_to_event(row) for row in rows]

    def get(self, event_id: str) -> EvidenceEvent | None:
        with sqlite3.connect(self.path) as conn:
            conn.row_factory = sqlite3.Row
            row = conn.execute(
                "SELECT * FROM evidence WHERE id = ?", (event_id,)
            ).fetchone()
        return self._row_to_event(row) if row else None
```

```python
"""Post-submission review: context, prompt, parsing."""

from __future__ import annotations

import json
import re
from dataclasses import dataclass, field

from testbridge.content.repository import ContentPack
from testbridge.contract.models import ShortAnswer
from testbridge.evidence.store import EvidenceEvent
from testbridge.tutor.context import build_context

MAX_EXPLANATION_CHARS = 4000
MAX_LIST_ITEMS = 3
VERDICTS = ("correct", "partial", "incorrect")

_FENCE_RE = re.compile(r"^```(?:json)?\s*|\s*```$", re.IGNORECASE)


@dataclass(frozen=True)
class ReviewContext:
    lesson_id: str
    exercise_id: str
    exercise_type: str
    text: str
    dimensions: list[str]


@dataclass(frozen=True)
class RubricVerdict:
    dimension: str
    met: bool
    comment: str


@dataclass(frozen=True)
class TutorReview:
    verdict: str
    explanation: str
    strengths: list[str] = field(default_factory=list)
    gaps: list[str] = field(default_factory=list)
    rubric: list[RubricVerdict] = field(default_factory=list)
    suggested_score: float | None = None


REVIEW_SYSTEM_PROMPT = (
    "你是 TestBridge 的讲评助手。学习者刚提交了一道练习，请针对这次作答讲评。\n"
    "规则：\n"
    "1. 用中文，先给结论，再给理由，300 字以内。\n"
    "2. 指出具体错在哪一步、或哪里写得好；不要泛泛而谈。\n"
    "3. 只使用 <lesson> 与 <submission> 里的信息；不要臆造 rubric 之外的维度。\n"
    "4. 只输出一个 JSON 对象，不要代码块、不要额外文字。格式：\n"
    '{"verdict": "correct|partial|incorrect", "explanation": "...", '
    '"strengths": ["..."], "gaps": ["..."], '
    '"rubric": [{"dimension": "...", "met": true, "comment": "..."}], '
    '"suggested_score": 0.0}'
)


def _answer_text(exercise) -> str:
    answer = exercise.answer
    if answer is None:
        return "（无）"
    if isinstance(answer, ShortAnswer):
        return (
            "接受关键词：" + "、".join(answer.accepted)
            + f"（至少命中 {answer.min_hits} 个）"
        )
    if isinstance(answer, list):
        return "、".join(answer)
    return str(answer)


def build_review_context(pack: ContentPack, event: EvidenceEvent) -> ReviewContext:
    lesson_id = event.lesson_id or ""
    exercise = pack.exercises.get(event.exercise_id or "")
    if exercise is None:
        raise KeyError(f"unknown exercise: {event.exercise_id}")

    base = build_context(pack, lesson_id).text
    options = " ".join(f"{option.id}. {option.text}" for option in exercise.options)
    rubric_lines = [
        f"- {item.dimension}（权重 {item.weight}）：{item.criteria}"
        for item in exercise.rubric
    ]
    response = event.payload.get("response")
    lines = [
        "<submission>",
        f"题目：{exercise.prompt}",
        f"选项：{options or '（无）'}",
        "学习者答案：" + json.dumps(response, ensure_ascii=False),
        f"系统判定：{event.outcome}（{event.score}/{event.max_score}）",
        f"正确答案：{_answer_text(exercise)}",
        f"既有解析：{exercise.explanation or '（无）'}",
        "rubric：\n" + ("\n".join(rubric_lines) if rubric_lines else "（无）"),
        "</submission>",
    ]
    return ReviewContext(
        lesson_id=lesson_id,
        exercise_id=exercise.id,
        exercise_type=exercise.type,
        text=base + "\n\n" + "\n".join(lines),
        dimensions=[item.dimension for item in exercise.rubric],
    )


def render_review_prompt(context: ReviewContext) -> str:
    return "\n".join([
        f'<lesson id="{context.lesson_id}">',
        context.text,
        "</lesson>",
    ])


def _strings(value: object) -> list[str]:
    if not isinstance(value, list):
        return []
    return [item for item in value if isinstance(item, str) and item][:MAX_LIST_ITEMS]


def parse_review(raw: str, dimensions: list[str]) -> TutorReview:
    text = _FENCE_RE.sub("", raw.strip()).strip()
    try:
        data = json.loads(text)
    except json.JSONDecodeError:
        data = None

    if not isinstance(data, dict):
        return TutorReview(
            verdict="partial", explanation=text[:MAX_EXPLANATION_CHARS]
        )

    verdict = data.get("verdict")
    if verdict not in VERDICTS:
        verdict = "partial"

    explanation = data.get("explanation")
    if not isinstance(explanation, str) or not explanation.strip():
        explanation = text
    explanation = explanation.strip()[:MAX_EXPLANATION_CHARS]

    by_dimension = {}
    raw_rubric = data.get("rubric")
    if isinstance(raw_rubric, list):
        for item in raw_rubric:
            if not isinstance(item, dict):
                continue
            dimension = item.get("dimension")
            if dimension in dimensions and dimension not in by_dimension:
                by_dimension[dimension] = RubricVerdict(
                    dimension=dimension,
                    met=bool(item.get("met")),
                    comment=str(item.get("comment") or ""),
                )
    rubric = [by_dimension[item] for item in dimensions if item in by_dimension]

    score = data.get("suggested_score")
    suggested: float | None = None
    if dimensions and isinstance(score, (int, float)) and not isinstance(score, bool):
        suggested = max(0.0, min(1.0, float(score)))

    return TutorReview(
        verdict=verdict,
        explanation=explanation,
        strengths=_strings(data.get("strengths")),
        gaps=_strings(data.get("gaps")),
        rubric=rubric,
        suggested_score=suggested,
    )
```

```python
"""Cache of AI reviews keyed by the evidence they comment on."""

from __future__ import annotations

import json
import sqlite3
from dataclasses import dataclass
from pathlib import Path

from testbridge.learning.timeutil import iso, utcnow
from testbridge.tutor.review import RubricVerdict, TutorReview

SCHEMA_SQL = """
CREATE TABLE IF NOT EXISTS exercise_review (
  evidence_id     TEXT PRIMARY KEY,
  learner_id      TEXT NOT NULL,
  lesson_id       TEXT NOT NULL,
  exercise_id     TEXT NOT NULL,
  verdict         TEXT NOT NULL,
  explanation     TEXT NOT NULL,
  strengths_json  TEXT NOT NULL DEFAULT '[]',
  gaps_json       TEXT NOT NULL DEFAULT '[]',
  rubric_json     TEXT NOT NULL DEFAULT '[]',
  suggested_score REAL,
  model           TEXT NOT NULL,
  prompt_version  TEXT NOT NULL,
  created_at      TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_review_exercise
  ON exercise_review(learner_id, exercise_id);
"""


@dataclass(frozen=True)
class StoredReview:
    evidence_id: str
    learner_id: str
    lesson_id: str
    exercise_id: str
    verdict: str
    explanation: str
    strengths: list[str]
    gaps: list[str]
    rubric: list[RubricVerdict]
    suggested_score: float | None
    model: str
    prompt_version: str
    created_at: str


class ExerciseReviewStore:
    def __init__(self, path: Path) -> None:
        self.path = path
        path.parent.mkdir(parents=True, exist_ok=True)
        with sqlite3.connect(self.path) as conn:
            conn.executescript(SCHEMA_SQL)

    def put(
        self,
        *,
        evidence_id: str,
        learner_id: str,
        lesson_id: str,
        exercise_id: str,
        review: TutorReview,
        model: str,
        prompt_version: str,
    ) -> StoredReview:
        stored = StoredReview(
            evidence_id=evidence_id,
            learner_id=learner_id,
            lesson_id=lesson_id,
            exercise_id=exercise_id,
            verdict=review.verdict,
            explanation=review.explanation,
            strengths=list(review.strengths),
            gaps=list(review.gaps),
            rubric=list(review.rubric),
            suggested_score=review.suggested_score,
            model=model,
            prompt_version=prompt_version,
            created_at=iso(utcnow()),
        )
        with sqlite3.connect(self.path) as conn:
            conn.execute(
                """
                INSERT INTO exercise_review
                (evidence_id, learner_id, lesson_id, exercise_id, verdict,
                 explanation, strengths_json, gaps_json, rubric_json,
                 suggested_score, model, prompt_version, created_at)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(evidence_id) DO UPDATE SET
                  learner_id=excluded.learner_id,
                  lesson_id=excluded.lesson_id,
                  exercise_id=excluded.exercise_id,
                  verdict=excluded.verdict,
                  explanation=excluded.explanation,
                  strengths_json=excluded.strengths_json,
                  gaps_json=excluded.gaps_json,
                  rubric_json=excluded.rubric_json,
                  suggested_score=excluded.suggested_score,
                  model=excluded.model,
                  prompt_version=excluded.prompt_version,
                  created_at=excluded.created_at
                """,
                (
                    stored.evidence_id, stored.learner_id, stored.lesson_id,
                    stored.exercise_id, stored.verdict, stored.explanation,
                    json.dumps(stored.strengths, ensure_ascii=False),
                    json.dumps(stored.gaps, ensure_ascii=False),
                    json.dumps(
                        [
                            {"dimension": item.dimension, "met": item.met,
                             "comment": item.comment}
                            for item in stored.rubric
                        ],
                        ensure_ascii=False,
                    ),
                    stored.suggested_score, stored.model,
                    stored.prompt_version, stored.created_at,
                ),
            )
        return stored

    def get(self, evidence_id: str) -> StoredReview | None:
        with sqlite3.connect(self.path) as conn:

            evidence_id=row["evidence_id"],
            learner_id=row["learner_id"],
            lesson_id=row["lesson_id"],
            exercise_id=row["exercise_id"],
            verdict=row["verdict"],
            explanation=row["explanation"],
            strengths=json.loads(row["strengths_json"]),
            gaps=json.loads(row["gaps_json"]),
            rubric=[
                RubricVerdict(item["dimension"], item["met"], item["comment"])
                for item in json.loads(row["rubric_json"])
            ],
            suggested_score=row["suggested_score"],
            model=row["model"],
            prompt_version=row["prompt_version"],
            created_at=row["created_at"],
        )
```

```python
"""Orchestrate post-submission review and reference scoring."""

from __future__ import annotations

import sqlite3
from dataclasses import dataclass, replace

from testbridge.content.repository import ContentPack
from testbridge.evidence.store import EvidenceEvent, EvidenceStore, new_event
from testbridge.tutor.client import LlmClient
from testbridge.tutor.config import TutorConfig
from testbridge.tutor.review import (
    TutorReview,
    build_review_context,
    parse_review,
    render_review_prompt,
    REVIEW_SYSTEM_PROMPT,
)
from testbridge.tutor.review_store import ExerciseReviewStore, to_review

PROMPT_VERSION = "review/1"
SUPPORTED_KINDS = ("exercise_attempt", "self_assess")


class EvidenceNotFoundError(Exception):
    """The evidence is missing or belongs to another learner."""


class UnsupportedEvidenceError(Exception):
    """The evidence cannot be reviewed (wrong kind or unknown exercise)."""


@dataclass(frozen=True)
class ReviewReply:
    review: TutorReview
    cached: bool
    saved: bool
    evidence_event: EvidenceEvent | None


class ReviewService:
    def __init__(
        self,
        pack: ContentPack,
        evidence: EvidenceStore,
        reviews: ExerciseReviewStore,
        client: LlmClient,
        config: TutorConfig,
        learner_id: str = "local",
    ) -> None:
        self.pack = pack
        self.evidence = evidence
        self.reviews = reviews
        self.client = client
        self.config = config
        self.learner_id = learner_id

    def review(self, evidence_id: str, refresh: bool = False) -> ReviewReply:
        event = self.evidence.get(evidence_id)
        if event is None or event.learner_id != self.learner_id:
            raise EvidenceNotFoundError(evidence_id)
        if event.kind not in SUPPORTED_KINDS:
            raise UnsupportedEvidenceError(event.kind)
        exercise = self.pack.exercises.get(event.exercise_id or "")
        if exercise is None:
            raise UnsupportedEvidenceError(f"unknown exercise: {event.exercise_id}")

        if not refresh:
            stored = self.reviews.get(evidence_id)
            if stored is not None:
                return ReviewReply(
                    review=to_review(stored), cached=True, saved=True,
                    evidence_event=None,
                )

        context = build_review_context(self.pack, event)
        raw = self.client.complete(REVIEW_SYSTEM_PROMPT, render_review_prompt(context))
        review = parse_review(raw, context.dimensions)

        saved = True
        try:
            self.reviews.put(
                evidence_id=evidence_id,
                learner_id=self.learner_id,
                lesson_id=context.lesson_id,
                exercise_id=context.exercise_id,
                review=review,
                model=self.config.model,
                prompt_version=PROMPT_VERSION,
            )
        except sqlite3.Error:
            saved = False

        evidence_event = None
        if context.dimensions and review.suggested_score is not None:
            evidence_event = new_event(
                kind="llm_review",
                lesson_id=event.lesson_id,
                exercise_id=event.exercise_id,
                concept_ids=exercise.concepts,
                outcome="submitted",
                score=review.suggested_score,
                max_score=1.0,
                payload={
                    "evidence_id": evidence_id,
                    "model": self.config.model,
                    "prompt_version": PROMPT_VERSION,
                    "verdict": review.verdict,
                    "rubric": [
                        {"dimension": item.dimension, "met": item.met,
                         "comment": item.comment}
                        for item in review.rubric
                    ],
                },
                source="tutor",
                learner_id=self.learner_id,
            )
            previous = self._previous_review(evidence_id)
            if previous is not None:
                evidence_event = replace(evidence_event, supersedes=previous.id)

        return ReviewReply(
            review=review, cached=False, saved=saved,
            evidence_event=evidence_event,
        )

    def _previous_review(self, evidence_id: str) -> EvidenceEvent | None:
        rows = self.evidence.list(kind="llm_review", limit=1_000)
        matches = [
            row for row in rows
            if row.payload.get("evidence_id") == evidence_id
        ]
        if not matches:
            return None
        return max(matches, key=lambda row: (row.created_at, row.id))
```

```javascript
      const table = document.createElement("table");
      payload.rubric.forEach((item) => {
        const row = document.createElement("tr");
        [item.dimension, item.met ? "达成" : "未达成", item.comment].forEach((text) => {
          const cell = document.createElement("td");
          cell.textContent = text;
          row.appendChild(cell);
        });
        table.appendChild(row);
      });
      container.appendChild(table);
    }

    if (payload.suggested_score !== null && payload.suggested_score !== undefined) {
      const score = document.createElement("p");
      score.className = "tb-review-score";
      score.textContent =
        "参考分 " + payload.suggested_score.toFixed(2) + "（" + payload.model + "，不参与掌握度）";
      container.appendChild(score);
    }
  }

  function maybeAddReviewButton(form, evidenceId) {
    if (!tutorEnabled() || !evidenceId) return;
    if (form.querySelector(".tb-review-button")) return;
    const box = document.createElement("div");
    box.className = "tb-review";
    const button = document.createElement("button");
    button.type = "button";
    button.className = "tb-review-button";
    button.textContent = "让 AI 讲讲";
    button.addEventListener("click", async () => {
      button.disabled = true;
      const original = button.textContent;
      button.textContent = "正在讲评…";
      try {
        const response = await fetch("/api/review", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ evidence_id: evidenceId }),
        });
        const payload = await response.json();
        if (!response.ok) {
          throw new Error(payload.detail ? payload.detail.message : "讲评失败");
        }
        renderReview(box, payload);
      } catch (err) {
        box.textContent = "讲评失败：" + err.message;
      } finally {
        button.disabled = false;
        button.textContent = original;
      }
    });
    box.appendChild(button);
    form.appendChild(box);
  }
```
