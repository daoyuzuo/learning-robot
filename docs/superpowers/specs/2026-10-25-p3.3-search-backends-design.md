# P3.3 检索后端与路由设计（Search Backends）

- 状态：Implemented，2026-10-25
- 范围：插件化检索后端、OpenAlex 适配器、按主题自动路由与回退、草稿级手动覆盖、收紧溯源信任
- 上游：[P3.1 内容工作台](2026-10-25-p3.1-content-studio-design.md)、[P3.2 质量门禁](2026-10-25-p3.2-quality-gates-design.md)
- 路线图：[ROADMAP](../../ROADMAP.md)

---

## 1. 目标

P3.1/P3.2 的调研只有 DeepSeek Search 一个来源。P3.3 增加第二个真实来源，并把“选哪个源”变成可解释、可覆盖的规则：

- 新增 **OpenAlex** 后端，面向论文/学术主题。
- 保持 `SearchProvider` 协议不变，新增 `SearchRouter` 负责选择与回退。
- 自动路由：学术主题走 OpenAlex，文档主题走 DeepSeek；首选无命中或失败时回退。
- 草稿级手动覆盖：`auto | deepseek | openalex`，手动选择不回退。
- 收紧溯源：资源必须来自 A/B 级命中，关闭 P3.2 的“C 级来源可标成 trust A”缺口。
- 调研档案记录实际使用的后端，页面可见。

**本期只实现 OpenAlex。** SearXNG / Firecrawl / arXiv 只留接口位置，不实现。

## 2. 非目标

- SearXNG、Firecrawl、arXiv 适配器。
- 网页正文抓取（`fetch` 仍返回空串）。
- 跨后端扇出查询、结果缓存、去重以外的合并策略。
- 引用数、期刊分区、影响因子等更细的可信度算法。
- 修改 DeepSeek Search 的请求/响应语义。
- 修改内容契约 `tb/1`。

## 3. 决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 本期后端 | 只加 OpenAlex | 免费、无需 key，直接覆盖论文型主题 |
| 路由形态 | Router 返回 provider，不改 `run_research` | 无共享状态，多课可并行调研 |
| 路由信号 | 关键词 + concept.domain | 确定性、可测；不依赖模型输出 |
| 回退 | auto 逐查询回退；手动不回退 | 自动模式要成功率，手动模式要可预期 |
| 手动覆盖 | `draft.json.search_backend` | 作者可强制指定来源 |
| authority | 评审 A / 预印本 B / 其他 C / 撤稿 D | 与 P3.2 的 A/B 资源门禁一致 |
| 插件机制 | Protocol + 字典注册 | 不引入 entry points/pluggy，YAGNI |
| 配置 | 环境变量，无 key | 沿用 P2/P3.1 的密钥边界 |
| 引擎边界例外 | studio 路由词表 | 核心引擎保持内容无关；路由词表是作者层的确定性配置，不写内容包、不参与判分 |

## 4. 术语与信号

### 4.1 后端值

`search_backend` 只能是：

- `auto`（默认）：关键词/domain 路由 + 回退。
- `deepseek`：只查 DeepSeek，不回退。
- `openalex`：只查 OpenAlex，不回退。

旧草稿没有该字段时视为 `auto`。

### 4.2 学术关键词

主题与概念标题拼接后小写匹配，包含任一即视为学术信号：

```
论文, 综述, 研究, 数据集, 基准, 具身智能, 机器人学习, 强化学习, 模仿学习,
大模型, 基础模型, 扩散策略, 仿真到现实
paper, survey, benchmark, dataset, state of the art, sota, vla,
vision-language-action, embodied ai, robot learning, reinforcement learning,
imitation learning, foundation model, diffusion policy, sim-to-real, sim2real
```

不加入“感知 / 规划 / 控制 / robotics”等宽泛词，避免 ROS2 文档课误判为论文主题。

### 4.3 学术 domain

任一概念 `domain`（小写、去空白）属于以下集合即视为学术信号：

```
ai, ml, research, embodied-ai, machine-learning, computer-vision, nlp
```

`ros2`、`automotive`、`testing` 等不属于学术 domain。

### 4.4 路由名称

`SearchRoute.name` 用于档案与页面展示：

- `deepseek` / `openalex`：手动选择。
- `auto:openalex->deepseek` / `auto:deepseek->openalex`：自动路由 + 回退。
- `auto:<name>`：只有一个后端可用时的自动路由，不做回退。
- `custom`：调用方传入的不是 `SearchRouter`（测试或自定义 provider）。

## 5. 架构

```
src/testbridge/studio/search.py           # 现有 SearchHit / SearchProvider / DeepSeekSearch / trust_for
src/testbridge/studio/search_openalex.py  # OpenAlexSearch
src/testbridge/studio/search_router.py    # 学术判定、FallbackSearch、SearchRoute、SearchRouter
web/studio.py                             # 选择 provider，记录 backend
web/app.py                                # 组装 SearchRouter
```

### 5.1 接口

```python
# search_openalex.py
class OpenAlexSearch:
    def __init__(
        self,
        *,
        mailto: str | None = None,
        base_url: str = "https://api.openalex.org",
        transport: httpx.BaseTransport | None = None,
        retry_delay: float = 1.0,
        timeout: float = 10.0,
    ) -> None: ...

    def search(self, query: str, count: int = 10) -> list[SearchHit]: ...
    def fetch(self, url: str) -> str: ...  # 返回 ""

# search_router.py
@dataclass(frozen=True)
class SearchRoute:
    name: str
    provider: SearchProvider

def is_academic(
    topic: str,
    concept_titles: list[str],
    concept_domains: list[str],
) -> bool: ...

class FallbackSearch:
    def __init__(self, primary: SearchProvider, secondary: SearchProvider) -> None: ...
    def search(self, query: str, count: int = 10) -> list[SearchHit]: ...
    def fetch(self, url: str) -> str: ...

class SearchRouter:
    def __init__(self, providers: dict[str, SearchProvider]) -> None: ...
    def route(
        self,
        backend: str,
        *,
        topic: str,
        concept_titles: list[str],
        concept_domains: list[str],
    ) -> SearchRoute: ...
```

`SearchRoute.provider` 必须满足现有 `SearchProvider` 协议；`run_research` 不需要知道路由。

### 5.2 数据流

```
generate_research(draft, lesson)
  -> route = route_for(search, draft, plan, concepts)
  -> result = run_research(plan, titles, route.provider, budget, progress, backend=route.name)
  -> write_research(...)
  -> steps.research[lesson].backend = route.name
```

`route_for` 规则：

- `search` 有 `route` 方法 → 调用 `search.route(draft.get("search_backend", "auto"), ...)`。
- 否则 → `SearchRoute("custom", search)`，保持现有测试与自定义 provider 兼容。

### 5.3 调研结果扩展

- `ResearchResult` 增加 `backend: str = ""`（放在字段末尾，保持现有位置参数兼容）。
- `research/<lesson>.json` 增加 `"backend": "<route name>"`。
- `steps.research[lesson]` 增加 `"backend": "<route name>"`。
- 页面调研行显示后端名称。

## 6. 路由与回退

### 6.1 手动选择

- `deepseek`：`SearchRoute("deepseek", providers["deepseek"])`。
- `openalex`：`SearchRoute("openalex", providers["openalex"])`。
- 请求的后端不存在 → 抛 `SearchError("backend not configured: <name>")`。
- 手动选择**不**回退；查询失败记该查询失败，继续其它查询。

### 6.2 自动路由

- `is_academic(...)` 为真：primary = `openalex`，secondary = `deepseek`。
- 否则：primary = `deepseek`，secondary = `openalex`。
- 返回 `SearchRoute(f"auto:{primary}->{secondary}", FallbackSearch(primary, secondary))`。
- 如果只有一个 provider 可用：直接返回该 provider，名称为 `auto:<name>`，不做回退。
- 未知 `search_backend`（手改草稿）→ 按 `auto` 处理。

### 6.3 回退语义

`FallbackSearch.search(query, count)`：

1. 调 primary。
2. primary 返回非空 → 返回。
3. primary 返回空列表或抛 `SearchError` → 调 secondary。
4. secondary 返回非空或空列表 → 返回 secondary 结果。
5. secondary 也抛 `SearchError` → 抛 `SearchError("primary failed: ...; secondary failed: ...")`。

`fetch` 同样先 primary 后 secondary，空串视为无结果。

`run_research` 对每个查询单独调用 provider，因此回退是逐查询的；预算仍按查询数计。

## 7. OpenAlex 适配器

### 7.1 请求

```
GET {base_url}/works
  ?search=<query>
  &per-page=<clamp(count, 1, 50)>
  &mailto=<mailto>        # 仅当配置了 mailto
```

- `base_url` 默认 `https://api.openalex.org`，去掉末尾 `/`。
- `timeout` 默认 10 秒。
- 429 / 5xx / 超时 / `httpx.HTTPError`：退避 `retry_delay` 重试一次；仍失败抛 `SearchError`。
- 其它 4xx：立即抛 `SearchError("openalex status <code>")`。
- 2xx 非 JSON：抛 `SearchError("openalex returned non-JSON")`。
- `results` 缺失或不是数组：返回 `[]`。
- 单条结果不是对象或无 URL：跳过。

### 7.2 字段映射

| SearchHit | OpenAlex 来源 |
|---|---|
| `title` | `display_name` 或 `title`，缺省空串 |
| `url` | DOI URL → `primary_location.landing_page_url` → `open_access.oa_url` → `https://openalex.org/<id>` |
| `snippet` | 摘要前 300 字 |
| `summary` | 还原后的摘要 |
| `content` | 还原后的摘要 |
| `authority` | 见 §7.3 |
| `date` | `publication_date`；否则 `publication_year` 字符串；否则 `None` |

DOI 归一化：

- `https://doi.org/10.x/y` 原样；
- `doi:10.x/y` 去掉 `doi:` 前缀后补 `https://doi.org/`；
- 裸 `10.x/y` 补 `https://doi.org/`。

`url` 必须以 `http://` 或 `https://` 开头；否则退回 OpenAlex work URL（`id` 字段）。没有可用 URL 的结果跳过。

摘要还原：`abstract_inverted_index` 是 `{word: [positions]}`；按位置排序拼接，缺失/非法结构返回空串。

### 7.3 authority

| 条件 | authority | trust |
|---|---|---|
| `is_retracted` 为真 | -1 | D |
| `type` ∈ `article` / `review` / `book-chapter` / `proceedings-article` | 3 | A |
| `type` == `preprint` | 2 | B |
| 其他类型或缺失 | 1 | C |

`trust_for` 继续使用现有映射，不在 OpenAlex 模块里重复定义。

### 7.4 配置

| 环境变量 | 必填 | 默认 | 作用 |
|---|---|---|---|
| `TESTBRIDGE_OPENALEX_MAILTO` | 否 | 空 | 进入 OpenAlex polite pool；不写日志 |
| `TESTBRIDGE_OPENALEX_BASE_URL` | 否 | `https://api.openalex.org` | 测试/代理覆盖 |
| `TESTBRIDGE_OPENALEX_TIMEOUT` | 否 | `10` | 秒；非法值用默认 |

无需 API key。密钥仍只从环境变量读取，不落盘、不回显、不写日志。

## 8. 草稿与 Studio

### 8.1 草稿字段

`draft.json` 增加可选字段：

```json
"search_backend": "auto"
```

- `DraftStore.create(..., search_backend: str = "auto")`。
- 合法值：`auto` / `deepseek` / `openalex`；非法值抛 `DraftError("invalid_search_backend", ...)`。

- `studio/1` 是草稿内部 schema，新增可选字段不升版本；不影响 `tb/1` 内容契约。

### 8.2 页面

- 草稿页 meta 行显示当前选择。

## 9. 收紧溯源信任（P3.2 修订）

### 9.1 新规则

- “可追溯”定义改为：资源的归一化 URL 出现在**至少一条 A/B 级命中**里。
- 新硬错误 `quality.resource_untrusted_source`：资源 URL 出现在命中里，但那些命中都不是 A/B。
- `quality.resource_unsourced` 保留：URL 完全不在任何命中。
- `provenance.traceable` 指标只统计 A/B 命中可回溯的资源。

### 9.2 影响

- 模型不能再把 C 级 OpenAlex 命中标成 `trust: A` 混过门禁。
- 现有 `content-packs/` 没有调研档案，`tb quality` 结构模式不受影响。
- Studio 生成的草稿若资源只来自 C/D 命中，定稿会被阻断，需改用 A/B 来源。

### 9.3 文档

- 同步修改 P3.2 spec §4.3 / §5.1 / §6，并标注 “Amended by P3.3”。
- 更新 P3.2 测试与 §14 验收。

## 10. 错误处理

| 场景 | 行为 |
|---|---|
| OpenAlex 429/5xx/超时 | 重试一次；仍失败 `SearchError`；auto 回退，手动记失败 |
| OpenAlex 返回坏 JSON | `SearchError`；同上 |
| OpenAlex 无摘要 | 命中保留，`summary`/`content` 为空，`snippet` 为空 |
| OpenAlex 无 URL | 跳过该条 |
| 后端未配置 | `SearchError("backend not configured: ...")`；auto 只用可用后端 |
| 手动后端失败 | 该查询记 failed，继续其它查询；不回退 |
| 旧草稿无 `search_backend` | 按 `auto` |
| 非法 `search_backend` | 新建时 400；手改草稿按 `auto` |

## 13. 风险

| 风险 | 取舍 |
|---|---|
| 关键词路由误判 | 只收强学术词；手动覆盖兜底；domain 辅助 |
| OpenAlex 摘要缺失 | 命中仍可用作来源；模型可看标题/URL |
| OpenAlex 限流 | mailto polite pool + 单次重试；失败回退 |
| 预印本质量参差 | 预印本只到 B；A/B 门禁仍要求元数据完整 |
| 手动选择无结果 | 作者明确选择时尊重选择，不偷偷换源 |
| 溯源收紧误伤旧草稿 | 旧草稿重新校验时会暴露；定稿门禁每次重算 |
