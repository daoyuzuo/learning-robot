# 机器人测试与质量体系 Resources

## Knowledge

### 通用测试与质量方法

- [ISO/IEC/IEEE 29119-2:2013 测试过程](https://www.iso.org/standard/56736.html)
  测试策略、测试计划、准入准出的过程框架。用于：M01 策略与分层、M02 回归。
- [ISO/IEC/IEEE 29119-4:2021 测试技术](https://www.iso.org/standard/79430.html)
  等价类、边界值、判定表、状态迁移等技术。用于：M01 测试设计。
- [ISTQB 官方术语表](https://glossary.istqb.org/en_US/home)
  统一 defect、test condition、test oracle 等术语。用于：M01/M02 全部课程。
- [ISO 12100:2010 机械安全风险评估](https://www.iso.org/standard/51528.html)
  危险识别、风险估计与风险降低的基准。用于：M01 风险分级、M03 安全标准。
- [ISO/TR 14121-2:2012 风险评估实用指南](https://www.iso.org/standard/57180.html)
  风险评估工具与示例。用于：M01 风险分级。

### 机器人安全与功能安全

- [ISO 10218-1:2025 工业机器人安全](https://www.iso.org/standard/73933.html)
  机器人本体安全设计。用于：M03 机器人安全标准。
- [ISO 10218-2:2025 机器人应用与单元](https://www.iso.org/standard/73934.html)
  工作站集成、调试、维护。用于：M03 机器人安全标准。
- [ISO/TS 15066:2016 协作机器人](https://www.iso.org/standard/62996.html)
  功率与力限制、速度与分离监控。用于：M03 协作应用。
- [ISO 3691-4:2023 无人驾驶工业车辆](https://www.iso.org/standard/83545.html)
  AGV/AMR 安全要求。用于：M03 移动机器人。
- [ISO 13482:2014 个人护理机器人](https://www.iso.org/standard/53820.html)
  服务机器人安全要求。用于：M03 服务机器人。
- [ISO 13849-1:2023 控制系统安全相关部件](https://www.iso.org/standard/73481.html)
  PL 等级与架构要求。用于：M03 功能安全。
- [ISO 13849-2:2012 验证](https://www.iso.org/standard/53640.html)
  安全功能与 PL 的验证。用于：M03 功能安全。
- [IEC 62061:2021+AMD1:2024](https://webstore.iec.ch/en/publication/93654)
  机械领域 SIL 路线。用于：M03 功能安全。
- [IEC 61508-2:2010](https://webstore.iec.ch/en/publication/5516)
  通用功能安全母标准。用于：M03 功能安全。

### 汽车与工业软件

- [ISO 21448:2022 SOTIF](https://www.iso.org/standard/77490.html)
  预期功能安全。用于：M03 感知/算法风险。
- [ISO/SAE 21434:2021 网络安全](https://www.iso.org/standard/70918.html)

### 性能评价

- [ISO 9283:1998 工业机器人性能](https://webstore.ansi.org/standards/iso/iso92831998)
  位姿/路径精度与重复性。用于：M03 性能评价。
- [ISO 18646-1:2016 轮式服务机器人运动](https://www.iso.org/standard/63127.html)
  运动性能测试。用于：M03 性能评价。
- [ISO 18646-2:2019 服务机器人导航](https://www.iso.org/standard/69057.html)
  导航性能测试。用于：M02 基线、M03 性能评价。
- [GB/T 38124-2019 服务机器人性能测试方法](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=620AE1ED4DAE1A58DF2570DF54B27FC4)
  国内服务机器人性能测试。用于：M03 性能评价、CQC。

### 市场准入

## Wisdom (Communities)

- 中国机器人检测认证联盟及 CQC 公开培训：了解 CR/CQC 认证流程和常见不符合项。
- VDA QMC / intacs 社区：ASPICE 评估实践和过程改进讨论。
- 机器人安全标准工作组与行业会议：跟踪 ISO 10218、ISO/TS 15066 的版本变化。

## Gaps

- 多数 ISO/IEC 标准全文需要购买；课程只能引用官方摘要和公开范围内的要求。
- 缺少可公开引用的真实机器人事故数据集；课程中的事故场景是教学化重构。
- 缺少国内 CNAS 实验室的具体测试案例和报告样例。
- 尚未收录具体求职社区/内推渠道；后续可由作者按目标市场补充。
