# 3. 自动化测试与测试框架

> 分册索引：[README.md](README.md)　|　标记：**核心** = 目标岗位直接需要；**扩展** = 面试/岗位加分；**可选** = 按方向选学。

## 3.1 框架分层

- 用例层、夹具/环境层、适配层、激励层、断言/预言层、证据层、调度层、集成层
- 数据与代码分离、配置管理、环境复位
- **核心**

## 3.2 设计模式与可维护性

- Adapter、Factory/Builder、Data-driven、Keyword-driven、Plugin
- 反模式：硬编码、隐式等待、全局状态、无清理、断言缺失
- **核心**

## 3.3 AI 辅助框架的“去黑盒化”

- 逐文件回读、依赖分析、数据流
- 识别 AI 生成风险：不存在的 API、过度抽象、复制粘贴、异常处理缺失、硬编码路径
- 自己重写核心模块、框架单测、设计决策记录
- **核心**

## 3.4 机器人适配层

- `DutAdapter` 接口设计
- CAN mock、ROS2 mock/最小实现
- 发布/订阅、服务调用、bag 读取
- 学习实验与生产项目的边界
- **核心**

## 3.5 测试数据与证据管理

- 用例数据、日志、bag、截图、波形、报告的统一命名与归档
- 失败现场保留、数据脱敏、体积管理
- **核心**

## 3.6 测试报告与看板

- 通过/失败/跳过/阻塞
- 指标趋势、失败分类、Top 缺陷、版本对比
- HTML/Markdown 报告
- **核心**

## 3.7 CI/CD

- 流水线：lint → unit → integration → HIL smoke → regression → report
- Jenkins/GitLab CI/GitHub Actions
- pytest 集成、制品归档、失败通知、并行/缓存
- HIL 资源锁、夜间回归、flaky test 隔离
- **扩展**
