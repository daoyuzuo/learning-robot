# 9. 项目迁移与表达

> 分册索引：[README.md](README.md)　|　标记：**核心** = 目标岗位直接需要；**扩展** = 面试/岗位加分；**可选** = 按方向选学。

## 9.1 项目盘点

- 3–5 个真实车载项目
- 背景、角色、策略、用例、自动化、缺陷、证据、指标
- **核心**

## 9.2 迁移矩阵

- 车载活动 → 机器人对应
- 可复用方法/工具/指标
- 差异与证据缺口
- **核心**

## 9.3 案例写作

- STAR + 证据 + 量化结果 + 迁移反思
- 3 个 1 页案例 + 3 分钟口述版
- **核心**

## 9.4 AI 辅助框架复盘

- 架构图、代码走读、重构、单测、README、局限
- **核心**

## 9.5 概念验证实验

- ROS2/Gazebo/TurtleBot3
- 虚拟 CAN
- 明确标注“学习实验”，不冒充生产项目
- **扩展**

## 9.6 简历与面试

- 三版简历：整机/系统、HIL/测试开发、硬件/部件
- 关键词、故事卡、模拟面试
- “没有机器人经验”的标准回答
- **核心**
