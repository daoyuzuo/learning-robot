# 4. 机器人系统通识

> 分册索引：[README.md](README.md)　|　标记：**核心** = 目标岗位直接需要；**扩展** = 面试/岗位加分；**可选** = 按方向选学。

## 4.1 机器人分类与场景

- 工业机械臂、移动机器人/AGV、协作机器人、四足、人形
- 典型场景：搬运、巡检、装配、服务、遥操作
- 类型—场景—关键指标
- **核心**

## 4.2 硬件子系统

- 计算平台：x86/ARM/Jetson
- 传感器：相机、LiDAR、IMU、编码器、力/力矩、触觉
- 执行器：电机、减速器、驱动、关节
- 电源/电池、机械结构、安全器件
- **核心**

## 4.3 软件栈

- 感知、定位/建图、规划、控制、任务/行为、HMI/云端
- 分层架构、状态机、行为树、生命周期、组件组合
- 各层接口与可观测点
- **核心**

## 4.4 通信架构

- ROS2/DDS、CAN/CANopen、EtherCAT、Ethernet
- 串口/SPI/I2C/Modbus
- 网络拓扑、带宽、实时性、时间同步
- **核心**

## 4.5 实时性与计算

- 控制周期、抖动、延迟、deadline
- CPU/GPU 负载、确定性、调度
- **核心**

## 4.6 安全架构

- 急停、安全 PLC、限速/限力、碰撞检测
- 安全状态、降级、恢复
- 协作机器人/AGV 安全
- **核心**

## 4.7 集成与故障传播

- 上电、标定、模式切换、异常恢复
- 故障跨层传播：传感器 → 控制 → 执行 → 整机 → 安全
- FMEA 草表
- **核心**

- 观测点 vs 注入点
